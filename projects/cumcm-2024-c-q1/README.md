# 2024 国赛 C 题第一问 · 可运行 MILP

用 2023 年数据建立 2024—2030 年七年联合优化模型，分别计算超产浪费和超产半价出售。两种情景已用附件实际求解并填入七个年份页。先读本页，再打开 [模型学习笔记](MODEL_NOTES.md) 对照代码。

## 三步复现

建议使用 Python 3.12。解压后在本项目目录运行。

```bash
python -m pip install -r requirements.txt
python solve.py --seconds 120 --gap 0.01
python export_excel.py
```

只试跑一种情景可加 `--scenario 1` 或 `--scenario 2`。两种 CSV 都生成后，再运行 Excel 导出。用 `--out trial` 可以把新结果放进独立目录，Excel 导出也传相同的 `--out trial`。默认最小面积比例是 10%，单种作物每季最多 12 块地，分别可用 `--min-fraction` 和 `--max-plots` 调整。上限设得太紧可能使问题无可行解。需要继续缩小最优性间隙时，可以增大 `--seconds`，例如先单独跑一个情景 600 秒。求解器在新运行中从头搜索，时间受机器影响。

| 文件 | 用途 |
|---|---|
| `solve.py` | 读取附件、建立并求解 MILP、按面积独立复核 |
| `export_excel.py` | 依年份、季次、地块名和作物名填写空白模板，并逐格读回核验 |
| `output/result1_*.xlsx` | 七年种植面积，单位亩。单季作物填在第一季区域 |
| `output/*_area.csv` | 每笔正面积，便于核算和后续可视化 |
| `output/*_sales.csv` | 按年份、季次和作物拆开产量、原价销量、超产量与收入 |
| `output/*_report.json` | 状态、利润上界、相对间隙、约束误差、逐年利润 |
| `data/` | 题面、两份输入附件和两份空白结果模板 |

## 本次运行

| 七年累计 | 超产浪费 | 超产半价 |
|---|---:|---:|
| 已核验方案利润（元） | 29,543,621.00 | 48,783,286.38 |
| 求解器给出的利润上界（元） | 41,171,429.59 | 63,586,561.93 |
| 相对最优性间隙 | 39.36% | 30.34% |
| 超产量（斤） | 4,538,335 | 8,116,255 |
| Excel 已核对的正面积单元格 | 570 | 574 |

两次均在 120 秒时间上限停机。当前结果是可行解，最优性仍未证实。相对间隙按“利润上界与当前利润之差 ÷ 当前利润”计算。面积、适种、重茬、水浇地模式、滚动豆类面积、分散度和最小面积均通过复核，按面积重算的利润也与求解器目标一致。

把浪费情景的种植方案改按半价规则结算，利润为 40,279,894.12 元。保持半价方案的种植面积并改按浪费规则结算，利润为 21,914,064.75 元。交叉核算能分清同一方案因计价规则获得的收入变化，以及换种植方案后的变化。
