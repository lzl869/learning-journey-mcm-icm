# 第一问模型学习笔记

## 1. 数据如何进入模型

| 来源 | 实际读取的字段 | 在模型里做什么 |
|---|---|---|
| 附件 1 · 乡村的现有耕地 | 地块名、地块类型、面积（亩） | 54 块地，其中 34 块露天地共 1201 亩，另有 20 个 0.6 亩的大棚 |
| 附件 1 · 乡村种植的农作物 | 作物编号、名称、类别和适种说明 | 41 种作物，识别粮食豆类、蔬菜豆类及不同地块的作季规则 |
| 附件 2 · 2023 年的农作物种植情况 | 地块、作物编号、作季、面积（亩） | 87 条历史记录，用于销量估算、2024 年重茬衔接及首个豆类窗口 |
| 附件 2 · 2023 年统计的相关数据 | 作物、地类、作季、亩产（斤/亩）、成本（元/亩）、价格区间（元/斤） | 107 条统计参数，按附注补齐 18 条智慧大棚第一季参数后共 125 条 |
| 附件 3 · 空白结果模板 | 年份页、季次、地块名、作物名称 | 把正种植面积填到对应格，空白表示未种植 |

清洗时先去掉名称首尾空格，对历史表合并地块列向下沿用，再用地块名和作物编号关联各表。把“单季”和“第一季”放进季槽 1，“第二季”放进季槽 2。季槽是汇总口径，各类地块的实际月份可以不同。

价格区间取中点，同一作物同一季用同一个价格，第二季允许不同价格。例如豇豆第一季为 8 元/斤，第二季为 9.6 元/斤。附件没有独立的成交量或预期销量表，因此以 2023 年同作物同季的估计总产量代理预期销量：

```text
D[s,j] = Σ_i 历史种植面积[i,s,j] × 亩产[地块类型(i),s,j]
```

例如，单季水稻历史面积为 22 + 20 = 42 亩，亩产 500 斤/亩，原价销量上限取 21,000 斤。小麦和玉米的单季估计上限分别为 170,840 和 132,750 斤。某个作物季次组合没有历史种植时，其原价销售额度取 0，仍可按相应情景处理超产。

## 2. 决策变量和目标函数

用 t 表示年份，i 表示地块，s 表示季槽，j 表示作物。

| 符号 | 含义 | 单位或类型 |
|---|---|---|
| x[t,i,s,j] | 在地块上分配给某种作物的面积 | 连续变量，亩 |
| z[t,i,s,j] | 对应地块、季次是否种该作物 | 0/1 变量 |
| u[t,s,j] | 全村该年该季该作物的原价销售量 | 连续变量，斤 |
| Q[t,s,j] | 同作物同季的全村总产量，由 x 计算 | 斤 |

```text
Q[t,s,j] = Σ_i 亩产[地块类型(i),s,j] × x[t,i,s,j]
0 ≤ u[t,s,j] ≤ D[s,j]
u[t,s,j] ≤ Q[t,s,j]

最大化七年利润
= Σ_(t,s,j) p[s,j] × (u[t,s,j] + α × (Q[t,s,j] − u[t,s,j]))
  − Σ_(t,i,s,j) 每亩成本[地块类型(i),s,j] × x[t,i,s,j]
```

α 在两种情景中分别取 0 和 0.5。原价收入总比超产收入高，因此对给定面积，利润最大化会把 u 推到 min(Q, D)。程序把收入改写为 p × [αQ + (1−α)u]，再最小化负利润以适配 SciPy 的接口。这里同时有连续面积和 0/1 选择，且所有变量仅作线性组合，所以是 MILP。

## 3. 从题意写出约束

| 规则 | 数学写法与含义 |
|---|---|
| 适种与季次 | 仅对附件允许的“地类 × 季次 × 作物”组合建变量。旱地、梯田、山坡地单季种非水稻粮食，普通棚一季菜一季菌，智慧棚两季菜 |
| 面积与最小规模 | 0.1 A[i] z ≤ x ≤ A[i] z。z=0 时面积为零，z=1 时至少占该地块的 10%。各启用季槽内 Σ_j x=A[i]，本版假定整季种满 |
| 水浇地模式 | 令 r=z[t,i,1,水稻]。稻作面积为 A[i]r，第二季面积总和为 A[i](1−r)，第二季选中作物数为 1−r。稻作年整块种稻，蔬菜年第一季可混种、第二季只能在大白菜、白萝卜、红萝卜中选一种 |
| 不连续重茬 | 同一地块、同一作物在相邻实际作季的两个 z 之和 ≤1。单季地检查相邻年份，双季地检查年内和跨年，水稻跨年检查跳过空白第二季。2024 年第一季衔接 2023 年该地块最后实际作季 |
| 三年轮豆 | 每块地在每个连续三年窗口内的豆类面积总和 ≥ A[i]，检查 2023—2025 至 2028—2030 六个窗口。第一个窗口计入历史豆类面积 |
| 分散度 | 对每年、每季、每种作物，跨地块求和 Σ_i z ≤12 |
| 当季销售 | 每个年份、季槽和作物分别核算，额度不跨年、跨季或跨作物挪用 |

10% 和 12 块是管理参数，题目没有规定统一数值。种满地块、同块地只要上一茬出现该作物就禁止下一茬再次出现，也是本版的建模口径。后者在混种时比逐小区重茬更严格。

轮豆按面积累计，地块面积表本身没有子地块坐标。要让累计面积真正落到每一小块地，可把地块面积从 0 到 A 编号成一个循环。将 2023 年豆类区作为起点，之后每季豆类区从上一次终点顺延，跨过 A 时从 0 接着排。历史数据每块地最多只有一季种豆，因此可用该季豆类区统一确定起点。任意三年窗口的连续走位累计达到 A 后，就能覆盖整个地块。这是依赖可自由安排作物在地块内位置的施工思路，当前 Excel 交付到地块与作物的面积层级。

## 4. 第一次上手可以先做这道小题

设某作物当季产 1,200 斤，原价销量上限 1,000 斤，单价 8 元/斤。先算两种收入，再对照 `build()` 里 u 的系数。答案分别为 8,000 元和 8,800 元，种植成本在两种情况下都要另扣。接着在 `result1_1_sales.csv` 找任意一行有超产的记录，用这套算法重算收入。

跑完整题时，先打开 `*_report.json` 看“实际相对间隙”，再看利润。面积合法性回答的是“方案能不能执行”，间隙回答的是“当前方案距离可证明的最优上界还有多大空间”。
